# Referent Verification

**CRITICAL**: A referent written from recollection reads exactly like a verified one. Recall is not a source.

## Decision Test — run before delivering any artifact that cites a referent

> **"Did I verify this referent (path, symbol, line, enumerated set) against its source in this session, or am I reconstructing it?"**

- Verified → cite it
- Reconstructed → verify it now, or mark it explicitly as unverified for the receiver
- An enumerated set a named source holds → point at the source; never re-type it

## Red Flags

| Thought | Reality |
|---|---|
| "I remember this file's name" | Recollection produces names that merely look right |
| "It was in context earlier" | Context holds paraphrases; the source holds the fact |
| "Marking it unverified looks sloppy" | The unmarked invented referent is the sloppy one |
